## 🌐 website/

CDN 기반 React 18 + Tailwind로 만든 **단일 파일 웹앱**. 빌드 도구 없이 `index.html` 하나로 동작합니다.

```
website/
├── index.html      # 전체 앱 (32KB)
└── thumbs/         # 릴스 썸네일 19장 (로컬 저장)
```

**실행**

```bash
cd website && npx serve .
```

또는 VS Code Live Server로 `index.html` 열기.

**구성**
- 히어로 — 수집 통계 4종
- 랭킹 카드 — 🥇 GUAP · 🥈 I WANT YOU BACK · 🥉 TUIDE 'GRLS' (클릭 시 해당 필터로 이동)
- 갤러리 — 릴스 카드 19장, 카테고리 7종 필터 + 인기순/최신순 정렬, 클릭 시 상세 모달
- 인사이트 · 데이터 한계

**기술 노트**
- 모든 CDN 버전 고정 (Babel은 반드시 7.x — 8.x는 인라인 `text/babel` 미지원)
- 썸네일은 로컬 저장 — 인스타 CDN 링크는 만료되므로 직접 링크하면 깨짐
- 카드의 재생 아이콘은 인스타 썸네일에 이미 박혀 있어 중복 표시하지 않음
